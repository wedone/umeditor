# 橙果APP签名算法技术文档

## 1. 概述
本文档详细描述了橙果APP（v8.96）接口请求中的 `sign` 签名生成算法，以及如何获取签名所需的密钥（Secret Key）。该算法用于验证请求的合法性，防止参数被篡改。

## 2. 签名算法详解

### 2.1 涉及参数
签名计算涉及以下参数：
1.  **context**: JSON格式的设备与环境信息字符串。
2.  **param**: JSON格式的业务参数字符串。
3.  **service**: 接口服务名称（如 `com.orange.note.query.problem.tag.page`）。
4.  **t**: 当前时间戳（秒级，10位数字）。

### 2.2 算法步骤

**步骤 1：参数准备**
收集所有参与签名的参数。如果参数中未包含时间戳 `t`，则需自动补全。

**步骤 2：参数排序**
将所有参数按照参数名（Key）的 ASCII 码顺序进行升序排序。
*   例如：`context` -> `param` -> `service` -> `t`

**步骤 3：参数拼接**
将排序后的参数以 `key=value` 的形式用 `&` 符号连接成一个字符串。
*   格式：`context={...}&param={...}&service=...&t=...`
*   **注意**：`context` 和 `param` 的值必须是原始字符串，不要进行 URL 编码。

**步骤 4：追加密钥**
在拼接好的字符串末尾追加 `&secretKey=` 和密钥值。
*   **当前密钥**: `LifeIsBeautifulWithGoodPeople@ShuCheng`
*   拼接后：`...&t=1716543210&secretKey=LifeIsBeautifulWithGoodPeople@ShuCheng`

**步骤 5：MD5 哈希**
对最终拼接的字符串进行 MD5 哈希计算，并将结果转换为**大写**字符串。
*   `sign = MD5(final_string).toUpperCase()`

### 2.3 示例代码 (JavaScript)

```javascript
// 密钥: LifeIsBeautifulWithGoodPeople@ShuCheng
function MD5(str) {
    return CryptoJS.MD5(str).toString().toUpperCase();
}

function generateAppSign(params) {
    // 1. 确保包含时间戳
    if (!params.t) {
        params.t = Math.floor(Date.now() / 1000).toString();
    }
    
    // 2. 按key排序
    const sortedKeys = Object.keys(params).sort();
    
    // 3. 拼接字符串
    const parts = [];
    for (const key of sortedKeys) {
        parts.push(`${key}=${params[key]}`);
    }
    const str = parts.join('&');
    
    // 4. 添加密钥
    const signStr = str + '&secretKey=LifeIsBeautifulWithGoodPeople@ShuCheng';
    
    // 5. MD5加密（大写）
    return MD5(signStr);
}
```

## 3. 密钥获取技术方案

### 3.1 原理
签名算法最终调用了 Native 层（`libsecurity.so`）中的 `zbw_md5` 函数进行哈希计算。在调用该函数之前，Java 层会将所有参数（包括密钥）拼接成一个完整的字符串。通过 Hook `zbw_md5` 函数，我们可以拦截并读取这个输入字符串，从而直接提取出密钥。

### 3.2 工具使用
为了应对未来密钥可能变更的情况，提供了以下工具用于快速获取最新密钥。

#### 3.2.1 准备工作
1.  确保电脑已安装 Frida 工具 (`pip install frida-tools`)。
2.  确保手机/模拟器已启动 `frida-server`。
3.  确保电脑与手机/模拟器已连接 (`adb devices` 可见)。

#### 3.2.2 获取密钥脚本 (`get_sign_key.js`)
此脚本会自动 Hook `libsecurity.so` 中的 `zbw_md5` 函数，并在控制台打印出包含密钥的原始签名字符串。

```javascript
// get_sign_key.js
Java.perform(function () {
    console.log("[*] 正在等待 libsecurity.so 加载...");
    
    // 监控库加载
    var libraryName = "libsecurity.so";
    var loaded = false;

    // 尝试直接Hook（如果已加载）
    var baseAddr = Module.findBaseAddress(libraryName);
    if (baseAddr) {
        console.log("[*] " + libraryName + " 已加载，基址: " + baseAddr);
        hookMD5(baseAddr);
        loaded = true;
    }

    // 如果未加载，则等待加载
    if (!loaded) {
        const android_dlopen_ext = Module.findExportByName(null, "android_dlopen_ext");
        if (android_dlopen_ext) {
            Interceptor.attach(android_dlopen_ext, {
                onEnter: function (args) {
                    this.path = args[0].readCString();
                },
                onLeave: function (retval) {
                    if (this.path && this.path.indexOf(libraryName) >= 0) {
                        console.log("[*] 检测到 " + libraryName + " 加载");
                        var baseAddr = Module.findBaseAddress(libraryName);
                        hookMD5(baseAddr);
                    }
                }
            });
        }
    }

    function hookMD5(baseAddr) {
        // zbw_md5 的偏移地址需要根据具体版本确定，或者直接通过符号查找
        // 这里使用符号查找，更通用
        var md5Func = Module.findExportByName(libraryName, "zbw_md5");
        
        // 如果找不到导出函数，尝试通过偏移（v8.96版本偏移可能不同，建议优先用Export）
        // 如果是 stripped binary，需要配合 IDA 分析确定偏移
        
        if (md5Func) {
            console.log("[*] 找到 zbw_md5 函数地址: " + md5Func);
            Interceptor.attach(md5Func, {
                onEnter: function (args) {
                    try {
                        // 读取第一个参数（输入字符串）
                        var inputStr = args[0].readCString();
                        console.log("\n[+] 捕获到签名计算!");
                        console.log("========================================");
                        console.log("[原始字符串]: " + inputStr);
                        
                        // 提取密钥
                        var match = inputStr.match(/&secretKey=([^&]+)/);
                        if (match && match[1]) {
                            console.log("[发现密钥]: " + match[1]);
                            console.log("========================================");
                        }
                    } catch (e) {
                        console.log("Error: " + e);
                    }
                }
            });
            console.log("[*] Hook 成功，请在APP中触发任意请求（如刷新列表）...");
        } else {
            console.log("[-] 未找到 zbw_md5 导出函数，尝试使用通用拦截...");
            // 备用方案：拦截 NativeSecuritySDK.signEncrypt
            var signEncrypt = Java.use("com.orange.note.security.NativeSecuritySDK");
            signEncrypt.signEncrypt.implementation = function(str) {
                console.log("\n[+] 捕获到 signEncrypt 调用!");
                console.log("========================================");
                console.log("[输入参数]: " + str);
                // 注意：这里可能还没拼接密钥，密钥是在 native 层拼接的
                // 所以必须 Hook native 层才能看到最终密钥
                return this.signEncrypt(str);
            }
        }
    }
});
```

#### 3.2.3 一键运行脚本 (`get_key.bat`)
双击运行此脚本即可开始监听。

```batch
@echo off
echo 正在启动 Frida 监听...
echo 请确保手机已连接且橙果APP正在运行...
frida -U -f com.orange.note -l get_sign_key.js --no-pause
pause
```

## 4. 常见问题
1.  **os 字段问题**：APP 实际发送的 `os` 字段值为 `Android\/13`（带转义），而浏览器通常发送 `Android/13`。务必在脚本中手动替换，否则签名验证会失败。
2.  **中文编码**：如果参数中包含中文，需要确保使用 UTF-8 编码，且在拼接前不要进行 URL 编码。
3.  **密钥变更**：如果请求返回签名错误，请运行 `get_key.bat`并在 APP 中刷新页面，获取最新密钥。
