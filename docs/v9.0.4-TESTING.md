## 核心改进

### 问题背景
高中数学中公式数量众多且复杂（矩阵、分段函数、积分等），原先的 MathQuill 验证机制存在以下问题：
1. **性能问题**：需要创建隐藏容器、加载 MathQuill jQuery 插件、实际渲染每个公式
2. **稳定性问题**：批量验证 50+ 公式时容易导致编辑器卡顿、保存出错
3. **跨域问题**：需要检测 iframe、访问 contentWindow，增加复杂度

### 解决方案
**从"验证后分类"改为"分类后渲染"**：

#### 旧流程（v9.0.2）
```
提取公式 → 批量 MathQuill 验证（慢）→ 标记失败公式 → 
  - 验证成功 → MathQuill HTML
  - 验证失败 → KaTeX 渲染为图片
```

#### 新流程（v9.0.3）
```
提取公式 → 复杂度判断（快）→ 
  - 简单公式 → MathQuill HTML（可编辑）
  - 复杂公式 → KaTeX 渲染为图片（快速、稳定）
```

## 技术实现

### 1. 新增 `isSimpleFormula` 函数
**位置**: `scripts/um-inject.user.js` 第 129-240 行

**检测规则**（满足任一条件即为复杂）：
- ✅ 复杂环境：`\begin{matrix}`, `\begin{cases}`, `\begin{array}`, `\begin{align}` 等
- ✅ 复杂符号：`\int_`, `\sum_`, `\prod_`, `\lim_` 等带下标的运算符
- ✅ 嵌套分数：`\frac` 嵌套 ≥3 层
- ✅ 公式长度：去空格后 >50 字符
- ✅ 括号嵌套：`\left`/`\right` 嵌套 ≥3 层

**简单公式示例**：
```latex
$x^2$                    # 单变量幂次
$\frac{a}{b}$           # 简单分数
$x + y = z$             # 基本运算
$\sqrt{x}$              # 根号
$a_1 + a_2$             # 下标
```

**复杂公式示例**：
```latex
$$\begin{cases}          # 分段函数（环境）
x+1, & x>0 \\
0,   & x=0 \\
x-1, & x<0
\end{cases}$$

$$\int_0^1 x^2 dx$$     # 积分（带下标）

$$\begin{pmatrix}        # 矩阵（环境）
1 & 2 \\
3 & 4
\end{pmatrix}$$
```

## 已知限制

1. **复杂度判断规则**：基于启发式规则，可能存在误判
   - 误判为简单：MathQuill 渲染失败会显示错误 → 可手动调整 `isSimpleFormula`
   - 误判为复杂：本应可编辑但变成图片 → 影响较小

2. **边界情况**：
   - 50 字符阈值可能不适合所有场景（可调整）
   - 3 层嵌套阈值可以根据实际需求调整
