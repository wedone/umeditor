本文档详细记录了橙果错题编辑器中源码到橙果码的转换规则。橙果码是橙果错题本系统使用的专用HTML格式，支持LaTeX公式渲染和特殊格式处理。

## 核心转换规则

### 1. LaTeX公式包装规则

**目标**: 将LaTeX公式包装在专用的公式容器中

#### 1.1 行内公式转换
- **输入模式**: `$...$`
- **转换规则**: 
  ```javascript
  result.replace(/\$([^$]+?)\$/g, function(match, formulaContent) {
      return '<span class="CgTex">$' + formulaContent + '$</span>';
  });
  ```
- **示例**:
  - 输入: `公式 $E=mc^2$ 很重要`
  - 输出: `公式 <span class="CgTex">$E=mc^2$</span> 很重要`

#### 1.2 括号公式转换
- **输入模式**: `\(...\)`
- **转换规则**:
  ```javascript
  result.replace(/\\\(([\s\S]+?)\\\)/g, function(match, formulaContent) {
      return '<span class="CgTex">$' + formulaContent + '$</span>';
  });
  ```
- **示例**:
  - 输入: `公式 \(x^2 + y^2 = z^2\) 是勾股定理`
  - 输出: `公式 <span class="CgTex">$x^2 + y^2 = z^2$</span> 是勾股定理`

### 2. HTML转义保护机制

**目标**: 转义普通文本中的HTML特殊字符，同时保护已处理的公式部分

#### 2.1 公式保护策略
- **保护范围**: 已包装在 `<span class="CgTex">...</span>` 中的内容
- **保护方法**: 使用临时标记替换公式，避免转义影响
  ```javascript
  const formulaRegex = /<span class="CgTex">[^<]*<\/span>/g;
  const formulas = [];
  let index = 0;
  
  // 提取并临时替换公式
  result = result.replace(formulaRegex, (match) => {
      formulas.push(match);
      return `__FORMULA_${index++}__`;
  });
  ```

#### 2.2 字符转义规则
- **转义字符**: `<` → `<`
- **实现代码**:
  ```javascript
  result = result.replace(/</g, '<');
  ```

#### 2.3 公式恢复
- **恢复方法**: 将临时标记恢复为原始公式内容
  ```javascript
  formulas.forEach((formula, i) => {
      result = result.replace(`__FORMULA_${i}__`, formula);
  });
  ```

### 3. 换行符处理

**目标**: 将文本换行符转换为HTML换行标签

- **转换规则**: `\n` → `<br>`
- **实现代码**:
  ```javascript
  result = result.replace(/\n/g, '<br>');
  ```
- **示例**:
  - 输入: `第一行\n第二行`
  - 输出: `第一行<br>第二行`

## 技术实现细节

### 正则表达式说明

#### 公式匹配正则
- `/\$([^$]+?)\$/g`: 匹配 `$...$` 格式的公式
  - `[^$]+?`: 非贪婪匹配，避免跨公式匹配
- `/\\\(([\s\S]+?)\\\)/g`: 匹配 `\(...\)` 格式的公式
  - `[\s\S]+?`: 匹配任意字符（包括换行符）

#### 公式保护正则
- `/<span class="CgTex">[^<]*<\/span>/g`: 匹配已包装的公式元素
  - `[^<]*`: 匹配不包含 `<` 字符的内容，避免嵌套标签问题
